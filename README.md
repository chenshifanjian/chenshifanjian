## 关注方向

- **桌面与系统**：Arch + niri（Wayland），DankMaterialShell 深度使用与插件开发
- **通信硬件**：Quectel EG25-G 4G 模块接入 Linux —— 短信、彩信、流量、定位全链路自建
- **安全**：NCRE/NCSE 信息安全技术、Web 与 Pwn 方向的练习与复盘
